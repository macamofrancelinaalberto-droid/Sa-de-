# Website – Saúde Mental (7º Grupo)

Site multipáginas sobre saúde mental e stress escolar, pronto para publicar no GitHub Pages.

## Ficheiros (tudo na mesma pasta)

```
website_saude_mental/
├── index.html
├── introducao.html
├── desenvolvimento.html
├── solucoes.html
├── recomendacoes.html
├── galeria.html
├── styles.css
├── stress1.jpg
├── stress2.jpg
├── stress3.jpg
└── README.md
```

**Não tem pastas** – é só arrastar todos os ficheiros de uma vez para o GitHub.

## Como publicar no GitHub Pages

1. Crie um repositório novo (ex: `saude-mental-escola`)
2. Arraste **todos** estes ficheiros de uma vez
3. Vá a **Settings → Pages**
4. Source: Deploy from a branch → `main` → `/ (root)`
5. Guarde e aguarde 1–2 minutos

O site ficará em:
`https://SEU-USUARIO.github.io/saude-mental-escola/`
